## LBX layout

| Layout | Files |
|---|---:|

| raw | 4 |

- **archive:** a table of 8-byte slots (u32 offset, u32 zero); the first offset is the table size and the last is the file size. No `0xFEAD` signature, no type word, no 0x200 name table. So the per-entry names and descriptions that MoO1 and MoM carry did not exist yet.
- **picture:** a bare 320×200 animation (`LOSE.LBX` 95 frames, `ORBIT.LBX` 250 frames, `WARP.LBX` 245 frames, `WIN.LBX` 300 frames). The header (width, height, current frame, frame count) is the one MoO1 / MoM pictures carry inside their LBX entries.
- **raw:** `DIPLOMAC.LBX`, `ISOUND.LBX`, `PICTLIB.LBX`, `RESEARCH.LBX`.
- **Archive entries:** 796 in 24 archives.
