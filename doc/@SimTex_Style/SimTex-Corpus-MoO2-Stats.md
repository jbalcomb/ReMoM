## LBX layout

- **360 LBX archives**, all type 0, 10,445 entries.
- **Header block size** (first entry offset): 0x800 ×360.
- **Name tables:** 0 of 360 archives have a printable 0x200 name table. The bytes after the offset table are uninitialised memory (e.g. `fonts.lbx` holds `ain palette` where a description field would be). So MoO2 dropped the per-entry names that MoO1 and MoM carry.
