# Presenting answers in chat

**Every file/function/line reference in chat is a clickable markdown link** — `[Combat.c:15086](MoM/src/Combat.c#L15086)`, never a bare path or a bare `file:line`. This holds for short lists, one-line answers, tables and summaries alike; brevity is never a reason to drop them. Full rule in `AGENTS.md` under *Presenting answers in chat*.
